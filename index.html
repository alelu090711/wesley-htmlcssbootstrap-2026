Primeira página usando HTML com Bootstrap

O Bootstrap é um framework de desenvolvimento front-end que facilita a criação de páginas e sistemas web com HTML, CSS e JavaScript

Em termos simples: ele fornece componestes e estilos prontos para você nao precisar criar tudo do zero
